# 提词器

一个免费、无需登录的手机网页提词器，适合口播视频创作者、课程讲解者和需要对镜头说话的人。粘贴稿件后，使用前置镜头拍摄，中文语音跟随帮助你看到下一行。

体验地址：https://hhsuny.github.io/teleprompter/

## 功能

- 中文语音跟随，支持点选文字定位、调整字号和行宽。
- 前后镜头录像、回看与导出，提词文字不会出现在成片里。
- 稿件与录像保存在浏览器本地，麦克风音频用于本地语音识别。
- 默认使用中文流式 Transducer 模型，首次联网下载约 30 MiB，后续使用浏览器缓存。
- 支持 iPhone Safari 添加到主屏幕，也可在其他支持相机和录制的手机浏览器尝试。

## 使用

1. 在手机浏览器打开体验地址，允许相机和麦克风权限。
2. 在「脚本」中输入稿件，返回「相机」并点击「试读」。
3. 选择支持的画质和帧率，拍摄后在「媒体」中回看、分享或下载。

实际支持的画质和帧率取决于手机和浏览器。iPhone 15 Safari 前置 1080P／60 帧尚未通过实测，可选择 30 帧拍摄。语音模型首次下载和设备性能会影响体验。浏览器清除网站数据可能删除本地稿件和录像，请及时导出。

## 本地开发

需要 Node.js 22 或更新版本。

```bash
npm ci
npm test
npm run build:pages
npm run dev
```

本项目使用 React、TypeScript、Vite、Sherpaw 和 sherpa-onnx。语音模型与第三方组件的来源及许可见 [开源组件说明](public/OPEN_SOURCE.txt) 和各模型目录中的清单。欢迎通过 GitHub Issues 提出问题或分享使用体验，喜欢这个项目也欢迎点 Star。
